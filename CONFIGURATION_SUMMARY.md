### Why HTTPS for Frontend Only?

- **Frontend (HTTPS)**: Encrypts data in transit from browser to server, protects cookies/tokens
- **Backend (HTTP)**: Runs behind the HTTPS proxy, so it's effectively encrypted
- **Development Benefit**: Simpler certificate management, no certificate errors
- **Production Note**: In production, both should use HTTPS with proper certificates
